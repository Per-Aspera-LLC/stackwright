# 🍽️ Restaurant Example — Otter Pipeline Reference Output

This directory contains the complete output of the Stackwright otter pipeline for a restaurant client (Ember Kitchen). It demonstrates what Brand Otter → Theme Otter → Page Otter produces for a simple 3-page neighborhood restaurant site.

## Files

| File | Produced By | Description |
|------|-------------|-------------|
| `BRAND_BRIEF.md` | Brand Otter 🦦🎨 | Brand discovery output |
| `stackwright.yml` | Theme Otter 🦦🌈 | Site config + terracotta/cream custom theme |
| `pages/content.yml` | Page Otter 🦦📄 | Home page |
| `pages/menu/content.yml` | Page Otter 🦦📄 | Menu page (tabbed by course) |
| `pages/reservations/content.yml` | Page Otter 🦦📄 | Reservations + contact page |

## How to Use

1. Scaffold a fresh Stackwright project:
   ```bash
   npx launch-stackwright ember-kitchen
   cd ember-kitchen
   ```

2. Copy these example files into the project:
   ```bash
   cp path/to/restaurant-example/BRAND_BRIEF.md .
   cp path/to/restaurant-example/stackwright.yml .
   cp -r path/to/restaurant-example/pages ./pages
   ```

3. Run the dev server:
   ```bash
   pnpm dev
   ```

## About This Example

- **Site type**: Restaurant / hospitality

- **Typography**: Lora (headings) + Source Sans 3 (body)
