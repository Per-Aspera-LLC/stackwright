## How to Use

1. Scaffold a fresh Stackwright project:
   ```bash
   npx launch-stackwright my-saas-site
   cd my-saas-site
   ```

2. Copy these example files into the project:
   ```bash
   cp path/to/saas-example/BRAND_BRIEF.md .
   cp path/to/saas-example/stackwright.yml .
   cp -r path/to/saas-example/pages ./pages
   ```

3. Run the dev server:
   ```bash
   pnpm dev
   ```
