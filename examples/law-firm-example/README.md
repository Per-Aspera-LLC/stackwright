## How to Use

1. Scaffold a fresh Stackwright project:
   ```bash
   npx launch-stackwright my-law-firm
   cd my-law-firm
   ```

2. Copy these example files into the project:
   ```bash
   cp path/to/law-firm-example/BRAND_BRIEF.md .
   cp path/to/law-firm-example/stackwright.yml .
   cp -r path/to/law-firm-example/pages ./pages
   ```

3. Run the dev server:
   ```bash
   pnpm dev
   ```
